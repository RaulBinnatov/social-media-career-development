# Social Media in Career Development

## Project Overview
This research project investigates how LinkedIn, Instagram, and X influence professional networking, recruiter visibility, and career opportunities among students and recent graduates.

## Research Methods
- Survey Research
- Descriptive Statistics
- ANOVA Analysis
- Chi-Squared Analysis
- Correlation Analysis

## Tools Used
- Google Forms
- Microsoft Excel
- GitHub
